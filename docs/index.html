Corpus retrieval demo

The from-scratch RAG retrieval pipeline running in the browser: splitting, hashed embeddings and exact cosine search.

The retrieval half of the research assistant, running in your browser over the repository's sample corpus — 9 chunks from 3 documents. Recursive splitting, a signed-hash embedder and exact cosine search, all written from scratch in the Python and ported here unchanged.

What this is and isn't

This is retrieval only. The agent layer — orchestrator, researcher, analyst, writer, critic — needs a language model, which a static page cannot host; run the repository locally with --fake-llm to exercise it with no model at all, or point it at Ollama.

The scores are not approximations. Buckets and signs are computed with a blake2b implementation checked bit-for-bit against Python's hashlib across all 2,313 corpus tokens, so a query term the corpus has never seen lands in exactly the bucket Python would give it. Verified against the Python retriever on five queries: identical ranking, and scores agreeing to 1e-4 — which is the rounding on the vectors shipped with this page.
